## Исправление

При отказе по уже полученному описанию обе реализации оставляли старые seller/image поля. Python регрессионный тест на старом коде воспроизвёл `unknown` вместо `marclemmor`. В тесте используется сохранённый настоящий seller-module `128121409205` и явно синтетическое описание неисправного контроллера; это воспроизведение transport-контракта, а не новый ручной вердикт об исходном iPhone.

В APK повторно используется свежий details-cache для предварительно отклонённых строк с тем же item/market/postal context. Новых запросов ради продавца нет, кэш другой почтовой зоны не используется. Отсутствующие поля не стирают известные. Неполная цена сохраняет unavailable_price. Полный refresh положительных лотов использует ту же функцию; все структурные проверки остаются обязательными.
