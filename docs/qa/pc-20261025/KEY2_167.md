## Почему потребовалась настройка

На странице Application Keys eBay прямо показывал Your keyset is currently
disabled и требование marketplace deletion/account closure notification.
Отправка запросов с таким набором давала 401 invalid_client. Для активации
подключён HTTPS-приёмник; освобождение «не сохраняю данные eBay» не выбиралось,
потому что бот сохраняет объявления и данные продавцов. Как был активирован
первый ключ, не проверялось. Для последующих наборов можно использовать тот же
приёмник, отдельно привязав его в eBay.

## Дополнительное исправление выбора ключей

При двух ключах старый общий счётчик мог быть положительным, хотя официальный
снимок первого приложения уже показывал0. Поэтому первый ключ показывался
доступным. Теперь выбор, проверка паузы, списание попытки и runtime учитывают
официальный нулевой остаток именно соответствующего приложения до его reset.
Положительный остаток другого приложения это не отменяет. Истёкший снимок не
блокирует новое окно; отдельный сетевой cooldown сохраняется.

Три новых проверки до исправления падали, после проходят. Всего593изолированных
Python PASS за101,995с. На копиях одного production checkpoint:paused
[false,false]→[true,false], выбор слота2 сохранён в обеих реализациях; факта
повторного выбора слота1 на этом production входе не утверждаем. Реальные eBay
запросы и запись в production для такого воспроизведения не выполнялись.

Серверная правка:[9f943716c68cf60adfb8f0f44ee72803a9f8a9d4](https://github.com/GitGayHub/e-monitor/commit/9f943716c68cf60adfb8f0f44ee72803a9f8a9d4).

выбор API-ключа, правила отбора и JSONschema1 не менялись. Телефон, эмулятор и

## Открытая обработка запросов удаления

После теста приходят настоящие уведомления eBay. Две реальные записи проверены
только чтением: в текущих production файлах/таблицах и локальном текстовом поиске
совпадений не найдено. Исторические Git-копии не проверены; полный размер
репозитория около10ГБ. Реальные записи остаются в закрытой очереди, не объявлены
обработанными и автоматически не удаляются. Данные запросов и полный архив
хранятся приватно; публичный отчёт не содержит идентификаторов субъектов.
Подтверждён и очищен только наш синтетический тест eBay с датой2021года.
Потребитель очереди и обработка исторических копий остаются открытой частью,
активацию ключа не выдавать за полную приёмку удаления всех данных.

Незавершёнными остаются40–50own на каждый товар, вся26/104приёмка,≤15мин и новый
