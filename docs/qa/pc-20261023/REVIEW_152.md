Журналы трёх завершённых успешных jobs — CLOCK_LOSS_EVIDENCE_152.json.

152 сохраняет точный itemEndDate из API-карточки, включая ещё не описанные кандидаты. Когда HTML не даёт часов, ранее полученное время используется исключительно для порядка проверки. Известный уже наступивший24-часовой период имеет приоритет над карточками с неизвестными часами. Лот за пределами окна остаётся ожидающим. Новое явно полученное время заменяет старое; неверные значения и даты без часового пояса не становятся таймером. При ограничении160ID ближайшие к окну часы не вытесняются потоком новых карточек без времени.

Сохранённые часы не подтверждают описание, цену или отправку. Каждый кандидат перед Telegram заново проходит собственное описание, модель, условия, текущую цену, доставку, время и дедупликацию. Не сохраняются цены/продавцы/текст объявления. Обычный аукцион по-прежнему ждёт24часа; правила Auktion+ не менялись. History47 и правила отбора товаров прежние.

Шесть новых контролей: передача точных часов из API через объединение, восстановление после перезапуска, будущее окно, исправленная свежая дата, ошибочные даты и давление более160ID. Исходная версия воспроизвела потерю поля/факта, целевой набор после правки14/14PASS. Ожидание одного прежнего теста усилено: известный наступивший срок теперь перед неизвестными часами. ## Скорость, API и текущий полный прогон APK

Два завершённых jobs(07:14–08:05UTC) показали реальный разрыв Pixel23мин35с, iPhone-обходов до7мин15с, но основного написания запроса iPhone до17мин49с. HTML-ошибки и незавершённые варианты не становятся пустой успешной выдачей.

Прежнее общее утверждение «API сейчас исчерпан» исправлено: в этих журналах есть148различимых ответов API,112с объявлениями. Последние настоящие отправки тоже используют API. Два отдельных read-only API-запроса12:03UTC прошли; productionсостояние не меняли.

У407307070487 API вернул itemCreationDate=23октября10:34:07 и itemOriginDate=21октября22:34:06. Расхождение минут UI Telegram и локального времени подтверждения тоже не использовать как точную сетевую задержку без отдельной проверки источника часов.
