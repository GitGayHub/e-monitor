# 0.154: неизвестная доставка больше не считается бесплатной

При ручной сверке настоящего сообщения153/120156 обнаружено расхождение: [мышь327411626248](https://www.ebay.de/itm/327411626248) отправлена с ценой19,17€, доставкой0€ и оценкой импорта9,41€. Текущая страница Chrome для Германии показывает «Ggf. kein Versand nach Deutschland», без котировки. Собственное описание продаёт целую мышь; отсутствие коробки и инструкции не делает её запчастью. Историческое состояние страницы в момент отправки не сохранено, поэтому текущую страницу нельзя выдавать за точную копию той отправки.

Причина воспроизведена на обеих реализациях: наличие собственного описания и цены товара считалось достаточным, когда модуль доставки не содержал числа. После этого прежний ноль из карточки попадал в итог. Пять отрицательных случаев нового набора падали до правки.

Теперь собственный shippingмодуль без распознаваемой котировки остаётся неполным; предупреждение о невозможной/неподтверждённой отправке в Германию не становится бесплатной доставкой даже рядом с общим Free shipping. Это htmlMoneyIncomplete: путьHTML→APIрезерв сохраняется; если резерв недоступен, подтверждённого положительного результата/уведомления/проверенной ценовой истории нет. Явная бесплатная доставка, известная платная доставка, самовывоз и платнаядоставка с необязательнымсамовывозом проверены отдельно. Отсутствующий целиком shippingмодуль не объявляется ни подтверждённым нулём, ни доказательством запрета; остальные прежние источники данных остаются в действии.
