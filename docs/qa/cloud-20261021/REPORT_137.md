Настоящие модули/селекторы остаются отказом; подтверждение конкретного выбранного телефона по прежнему строгому контракту сохранено. Устаревший вспомогательный Python probe исправлен тем же способом.

Общий публичный fixture — **28 сокращённых синтетических DOM-контролей**: CSS из этих страниц, script/comment, обычный текст, одиночный товар и 24 настоящих маркера. Матрица четырёх форматов проверяет пригодность, а не факт живого получения каждой корзины. Исходные приватные HTML/iframe дополнительно воспроизводятся в обоих парсерах; в GitHub сохранены только хеши и выводы. Приватный Gradle replay передаёт manifest явно и отключает повторное использование старого результата.
