## Есть ли проблемы с доставкой

**Да.** Журнал рабочего запуска [38949753040](https://github.com/GitGayHub/e-monitor/actions/runs/38949753040) содержит тайм-аут основного бота 19:12:56 UTC. Старая логика затем получила подтверждение 2049 через резервного бота для лота 128139444599. Проверка getMe установила, что это два разных бота. Основной запрос после тайм-аута также мог быть принят: отсутствие ответа не доказывает отсутствие сообщения.

В 0.101 ожидание ответа Telegram увеличено до 35 секунд. Неоднозначный тайм-аут больше не вызывает повтор через другого бота; состояние сохраняется до сетевого запроса и переживает перезапуск. Оно показывается как неподтверждённая доставка и не записывается в подтверждённую ленту. Явный отказ Telegram сохраняет возможность резервной отправки. Подтверждённый бот и маршрут теперь могут записываться в ленту/runtime и отображаться в APK. Старые записи не исправлялись выдуманными данными.

Низкое число уведомлений объясняется также получением и проверкой eBay: последняя зафиксированная рабочая порция 2026-10-16T19:49:30+00:00 → 2026-10-16T19:50:50+00:00 содержит 4 запрошенных поисков, 1 полностью загруженных, 427 карточек, 4 проверенных описаний и 0 отправок. Это не полный круг всех 48 поисков.

## Скорость и свежая проверка GitHub

На момент **2026-10-16T19:55:10+00:00** возраст последней HTML-попытки для 48 поисков составлял **4.34–27.38 минуты**, 26 старше 15 минут. Отсчёт взят по HTTP Date GitHub: часы ПК опережают сервер, поэтому локальное время не используется для этого сравнения. Эти величины измеряют попытки, а не успешное получение или задержку доставки. **Срок до 15 минут не достигнут и не подтверждён.**

Изолированная [проверка 0.101 из GitHub](https://github.com/GitGayHub/e-monitor/actions/runs/38958079111) получила выдачу, но полное описание 800366377085 вернуло `html_challenge`, HTTP 200. Она остановилась до создания заявки на отправку; `send=false`, сообщений не отправлялось. Слепой повтор не выполнялся. Chrome сейчас не предоставляется расширением для управления; свежая независимая сверка на ПК этим этапом не заявляется. Новые сообщения 0.101 также не прочитаны в Telegram: фоновое чтение текущего окна не содержит чат бота, окна не переключались.

HTML остаётся основным источником. API используется при ошибке или неполных данных и учитывает квоту. HTML не имеет этой API-квоты, однако сайт может возвращать SORRY, ограничение частоты или проверку доступа. Оба источника проходят общие проверки модели, назначения, полного описания, цены и права уведомления; непроверенное описание не считается положительным результатом. Равная полнота живой выдачи ещё не доказана.
