# Проверка 0.075 — 14 октября 2026

Исправлена подмена цены гибрида: если известна ставка, но неизвестна цена покупки, ставка больше не становится ценой Sofort. Обратная подмена тоже запрещена. Цена уточняется по подробностям, затем фильтры применяются снова. До уточнения лот не получает положительный результат и не отправляется. Нули сохраняются; неизвестная цена обозначается отдельно от дорогого товара и ожидания времени аукциона. Аукционная ставка не сравнивается с покупной медианой. Лишняя фраза о неизвестной цене предложения остаётся убранной.
