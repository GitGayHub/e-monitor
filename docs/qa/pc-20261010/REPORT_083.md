# Проверка 0.083 — общие условия и обратимые стоп-слова

Общая приёмка остаётся PARTIAL: 26 активных профилей /104 корзины. 50 сохранённых поисков, 48 активных. Все товары независимо ещё не проверены.

## Исправления

В прежнем updateSearchConditions категория, слова, состояние, регион и радиус менялись только в первом варианте. Теперь выбранная группа обновляется одной транзакцией, включая отключённые варианты. ID, формат продажи, bestOffer, enabled и notify сохранены. Цены без редактирования сохраняют прежние различия; явная правка, включая возврат к старому значению первого варианта, применяется ко всем. В редакторе и копировании показываются цены каждого варианта.

Редактор сравнивает правку с загруженной исходной записью. Неизменённая цена из старого черновика не перезаписывает более новую цену в базе. После сохранения исходное состояние редактора обновляется. Строки NaN, Infinity, отрицательные/нечисловые цены и неверный радиус не становятся пустыми настройками. Пустое значение и ноль остаются разными допустимыми значениями. Минимум поиска и лимит уведомлений не приравниваются.

Добавление своего слова в Stats.verify теперь относится к конкретному профилю, не к совпадению подстроки запроса. Оно меняет правило без неявного постоянного бана лотов. Снятие слова запускает обычную повторную проверку с актуальными условиями. Явное скрытие лота сохраняется. Ошибка записи видна; результат старого окна не меняет новое окно. Старые баны без известного происхождения автоматически не снимаются.
