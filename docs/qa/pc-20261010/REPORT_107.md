## Исправление

При исчерпании времени проверки описаний сохраняется приоритет поиска с ещё пригодными для уведомления кандидатами. Следующий допустимый проход сначала заново получает его выдачу и цену. В базе сохраняются только IDпоиска/время, не старая цена или описание. Если пауза180сек ещё действует, приоритет остаётся, остальные поиски идут дальше. Реальная попытка расходует приоритет; новый тайм-аут описания может сохранить его снова. Лимит двух кандидатов на товар не закрепляет один товар навечно. Отключённые уведомления и дорогие/ужеотправленные лоты не получают этот приоритет. Подход одинаков для основной страницы и дополнительных заканчивающихся аукционов.
