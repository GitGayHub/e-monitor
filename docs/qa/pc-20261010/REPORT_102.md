# Проверка 0.102 — 16 октября 2026

**Общая приёмка 26 товаров / 104 корзин остаётся PARTIAL.** Срок доставки до 15 минут пока не доказан.

## Найденные причины задержки

Планировщик ограничивал каждый проход восемью поисками даже при свободном времени, затем рабочий процесс ждал 60 секунд. Теперь проход с общим ограничением времени может продолжать очередь до своего безопасного срока. Режим без общего ограничения сохраняет предел восемь. Положение очереди сохраняется перед сетевым запросом, следующий запуск продолжает её. Пауза между проходами в новом workflow — 10 секунд; ограничение частоты каждого поиска 180 секунд, HTML первым и квота API сохранены. Уже запущенный workflow продолжает прежнюю паузу 60 секунд до штатного завершения: новая пауза вступит в силу в следующем запуске. Рабочий процесс не отменялся.

Тест настоящей цепочки normal→планировщик→HTML с 48 отдельными поисками подтверждает, что при четырёх секундах на запрос они все запрашиваются за 192 секунды без обращения к API. Это контролируемый тест, **не замер живого eBay**. Другие тесты сохраняют ограничение без общего deadline, трёхминутную паузу после попытки, квоту, очередь после перезапуска и кооперативное завершение медленного запроса.

## Понятный охват и счётчик описаний

Runtime schema1 получил необязательный searchCoverage: число активных поисков, сохранённых попыток, попыток за 15 минут перед обновлением, неизвестных и время самого давнего запроса. Это счётчик попыток, включая неудачные ответы, а не обещание успешного получения/уведомления. APK явно подписывает окно времени. Статус старого сервера без поля остаётся совместимым.

До исправления счётчик описаний рос только для принятых лотов. Теперь прочитанное собственное описание с дефектом или неправильной моделью тоже считается проверенным. Недоступное описание не считается прочитанным. Положительный вердикт, фильтры и медианы этим не менялись; History20 сохранена. Отдельный тест проверяет четыре прочитанных описания, из них два отказа, и одно недоступное, не создавая подтверждённую полную медиану.
