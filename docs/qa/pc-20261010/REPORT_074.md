# Проверка 0.074 — 14 октября 2026

Исправлена дополнительная причина ложной медианы: сервер записывал цены до проверки описания и модели, исключал дорогие товары и часть уже отправленных. Теперь история отделена от права уведомления. Ставки аукционов записываются отдельно от покупки. По указанию владельца лишняя фраза о неизвестной цене предложения остаётся убранной.

В Python и Android сохранены старые записи. Медиана и скидка используют только проверенную завершённую выборку текущих условий. Недоступное описание, неизвестная цена стороны гибрида или смена условий во время запроса не подтверждают завершённую историю. Лимит уведомления не сужает историю; минимальная цена, верхний предел, модель, состояние, регион и чёрные списки продолжают действовать. Изменение этих условий отделяет новую историю от старой. Telegram-меню тоже учитывает текущие условия и показывает для аукционов медиану ставки.
