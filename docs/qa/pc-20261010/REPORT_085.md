## Причины и изменения

PhoneRules и Python не учитывали немецкое «und» в комплекте. Теперь модель в начале названия с аксессуарами после соединителя отличает телефон с комплектом от комплекта запчастей. Деталь до соединителя остаётся деталью. Повреждённый экран полного телефона с моделью и памятью больше не превращает назначение товара в «продаётся дисплей»; оригинальный текст продолжает проверяться на неисправность.

Раньше «Display» отрабатывал как аксессуар до Burn-In. Добавлены конкретные подписи выгорания, учтены отрицания. Конкретная неисправность в названии имеет приоритет над общим состоянием «Als Ersatzteil». Фразы «без выгорания/без дефектов» не создают выдуманный дефект; реальная неисправность после «но» сохраняется. Два прежних теста были исправлены только в части неверного назначения «Display defekt = accessory»; добавлена проверка, что неисправный телефон по-прежнему отклоняется.

## HTML и API

В Python auto, Android превью, статистике и обычном мониторинге первым используется HTML. Обычный успешный ответ, включая подтверждённые нулевые результаты, не тратит API. При ошибке HTML или нехватке полного описания/живой цены используется ограниченный резерв API, если квота доступна. Исчерпанная квота не вызывает повторный цикл HTML→API→HTML. Пустой резервный ответ после ошибки не превращается в успешное «не найдено».

| Свойство | HTML | Browse API |
|---|---|---|
|Получение |Страницы поиска, лота и собственное описание продавца |Структурированный поиск и getItem|
|Лимиты |Нет счётчика Browse API; возможны429,капчи,блокировки и изменение разметки |Квота запросов и429; сохранённая пауза до восстановления|
|Описание |Свой iframe, без отзывов и рекомендаций |Своё описание getItem, без shortDescription вместо полного|
|Цена |Нужно разобрать покупку и ставку отдельно, доставку и выбранный вариант |Отдельные структурированные поля, но вариативный родитель не подтверждаетSKU|
|Одинаковый отбор |Общие правила модели, назначения, дефектов, цены, региона и повторных отправок |Те же правила после обновления деталей|

Положительный результат требует собственного полного описания и конечной неотрицательной живой цены. Неполная цена не даёт Telegram или подтверждённую медиану. Известный дефект можно объяснить даже при недоступной цене. HTML не обещает бесконечную доступность и не обходит капчи. При отсутствии обоих источников ошибка остаётся видимой. Свежий APIсравнительный запрос сейчас не выполнялся: квота исчерпана. Совпадение схем проверено тестами; это не доказательство идентичной живой выдачи всего каталога.
