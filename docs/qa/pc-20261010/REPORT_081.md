# APK 0.081 — проверка интерфейса и свежей выдачи

Общая приёмка **PARTIAL**. Каталог расширился: 50 записей поиска, 48 активных, 26 групп товаров / 104 корзины. Новый Pixel 9 Pro XL до 310 € сохранён на телефоне и принят сервером в ревизии e615b16e-02cf-490f-af8f-6e17ea104e6f; прежние 49 поисков сохранены.

0.081 исправляет отображение старого положительного результата во время перепроверки изменённых условий: показывается «Перепроверяется · прежний результат», положительный статус и «дешевле всех» до окончания скрыты. Это воспроизведено на 0.080 при добавлении слова Sony, затем исправлено; новая подпись пока не подтверждена отдельным живым повтором. Семантика фильтров прежняя: правила 1791978864 / HistoryVersion 4.

Через настоящий интерфейс изолированной копии APK проверен отсев в обе стороны. Подходящий PS5 999,99 € + 10,49 € при временном QA-лимите 1500 € принимается. Нажатие Sony добавляет своё слово; результат показывает «стоп-слово: Sony», цитату названия и кнопку снятия. Кнопка «Убрать своё стоп-слово … и перепроверить» возвращает оба проверенных PS5 в подходящие после проверки описаний. Диапазон 1009–1011 € оставляет 2 из 51 карточки. Временный лимит в QA восстановлен через интерфейс до 750 €; все 49 настроек, форматы, bestOffer и notify совпадают с исходной QA-копией за исключением времени правки. Производственные условия не менялись. Реальный тест обратного снятия в отдельном экране статистики ещё не выполнен.

На физическом телефоне карточка LG запустила проверку только этого товара. Все четыре корзины совпали с отдельным свежим прогоном Python по текущим условиям:
