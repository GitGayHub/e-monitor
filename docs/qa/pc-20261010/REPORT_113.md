# eMonitor 0.113 — проверка на эмуляторе

Исправлены две ошибки формы добавления. Общая проверка 26 товаров и 104 корзин ещё не завершена. Физический телефон не использовался.

## Что исправлено

**Старое название в новой форме.** После закрытия добавления новый экран показывал прежнее название, хотя внутри приложения запрос уже был пустым. Поля успевали запомнить старый текст до сброса модели. Теперь при открытии новой формы оба поля получают новый черновик. Проверено обычным интерфейсом: ввести название и алиас → закрыть → добавить заново. Оба поля пустые. [До исправления](images113/before-stale.png), [введённый черновик](images113/draft.png), [после исправления](images113/after-clean.png).

**Сообщение при отсутствии сети.** Когда не загрузился ни один формат, приложение показывало «Часть выдачи недоступна». В 0.112 исправлен приоритет общей ошибки; при том же отключении сети появилось «Нет сети». Wi-Fi и авиарежим эмулятора восстановлены. Успешная пустая выдача и частичная ошибка обрабатываются отдельно. Этот фикс сохранён в 0.113. [До](images112/before-offline.png), [после](images112/after-offline.png).
