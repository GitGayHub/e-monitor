# APK 0.082 — продолжение проверки при исчерпанной квоте

Общая приёмка остаётся PARTIAL: 26 активных профилей товара / 104 корзины. На телефоне 50 записей поиска, 48 активных; ещё один профиль отключён. [Сборка и сохранение данных](build082.json).

На рабочем сервере исчерпана квота Browse API. Переход на HTML действительно выполняется, но часть запросов и описаний недоступна. Ошибки показываются отдельно от «не найдено». Этот этап не доказывает доступность всех страниц.

Исправлены две причины потери прогресса. При остановке внутри поиска теперь сохраняется следующий ID лота в уже существующей базе серверных контрольных записей. После нового запуска оставшиеся лоты получают очередь; новые ID приоритетны, исчезнувший следующий лот заменяется следующим доступным. Изменение условий/правил или лимита сбрасывает эту позицию. Сохраняются только порядок ID и подпись условий: цены, описания и вердикты заново получаются и проверяются. Неполная выборка по-прежнему не подтверждает медиану.

Кроме времени на сохранение состояния оставлено небольшое окно для отправки полностью проверенных кандидатов. До исправления догрузка описаний могла использовать весь бюджет, после чего подготовленные уведомления также откладывались. Проверенный лот допускается к отправке; непроверенный не отправляется.

341 изолированный тест Python прошёл, включая пять новых проверок очереди и настоящего пути normal с подменённой отправкой. Они проверяют перезапуск, удалённый ID, новый ID, смену контекста, свежую изменённую цену и сохранение неполной истории. 312 Android / сборка успешны. Правила отбора товаров не менялись, HistoryVersion остаётся 4; новая версия исполнения 1791992886.

В «Обзоре» указано, когда получен сохранённый статус сервера. Даты применения настроек и успешного прохода переведены во время телефона. На физическом устройстве видны фактические ошибки и HTML после исчерпания квоты. Финальная APK 0.082 установлена на телефон и эмулятор; все 50 поисков и 3902/6625/510 исторических записей сохранены точно.

Публикация и применение сервером 0.082 ещё подтверждаются отдельно. Предыдущая проверка LG в APK 0.081 совпала с Python в четырёх корзинах. Фотография теста 120022 доставлена и её уведомление наблюдалось в AyuGram; полная новая подпись не читается в фоновом дереве клиента. Тест повторно не отправлялся, правила товаров после него не менялись. [Отчёт 0.081](REPORT_081.md).

Подключение Chrome к плагину после перерыва отсутствует. Новая серия PS5 содержит 40 собственных описаний, но полное независимое сопоставление каталога, всех вариантов запроса и корзин ещё не закончено. Следующие пункты: реальный серверный проход новой очереди, обратное снятие своего слова в статистике, новая подпись pending, точный вариант Nubia 267736285233 и оставшаяся ручная проверка после возвращения браузера.
