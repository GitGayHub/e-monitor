## Воспроизведённые ошибки отчёта

APK 0.057 через карточку одного товара, 29.263 с: 1024 / 1010.49 / 211.49 / 1110.49 €. Лот 940001176756 за 909.49 € присутствовал в отказах как «мимо запроса». Исправлено распознавание содержимого полноценной консоли без обязательного слова «mit»; кабель для устройства, только кабель, чехол и неверное поколение остаются отказами.

Проверен именно полный Python `process_searches` во временной конфигурации/базе/seen, с подменой отправки Telegram на сбор результата: этот прогон не отправлял сообщения. До исправления он показывал покупки 1150 / 1138 € и пустые аукционы. Все корзины проверялись по первому сохранённому варианту Sofort, а общая страница с аксессуарами не вызывала запрос только покупок. В 0.058 корзины получают собственные условия; заполненная общая страница вызывает отдельный запрос покупок. Живой повторный прогон: 1024 / 1010.49 / 212.49 / 909.49 €, все описания `verified`. Ставка обычного аукциона успела увеличиться на 1 €; он должен ждать времени, остальные три товара дороже 750 €.

На физическом телефоне 0.058 проверка только этой карточки завершилась за 55.099 с. Все четыре ID, суммы и статусы совпали с полным Python-прогоном ([снимок](ps5-four058.png)). Сервер подтвердил применение правил 1791727334 и прежней ревизии настроек. Отдельный явно обозначенный тест отчёта Telegram 119964 отправлен после подтверждения сервера; это проверка отчёта, а не уведомление о подходящем предложении. Наличие сообщения в клиенте отмечается отдельно в REPORT.md.
