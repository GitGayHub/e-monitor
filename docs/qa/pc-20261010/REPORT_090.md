# APK 0.090: проверка S25 Edge и исправления отбора

Общая задача остаётся PARTIAL (26 товаров /104 корзины). На этой выборке исправлены три конкретные ошибки, найденные независимой проверкой и сравнением исходных данных.

- [237086192631](https://www.ebay.de/itm/237086192631): коробка OVP/Box с названием модели и памятью ошибочно проходила как телефон. Прочитано полное описание (65 символов), проверена единственная фотография коробки. Теперь исключается как упаковка; цена 422,96 € не доказывает наличие телефона. Телефоны с OVP, «mit OVP/Box», originalverpackt, аксессуарами и без коробки сохраняются.
- [298705766786](https://www.ebay.de/itm/298705766786): название камеры, которой сделаны фотографии, ошибочно приводило к отказу Python по чужому бренду. Явная фраза о съёмке отделена от модели товара.
- [407236569883](https://www.ebay.de/itm/407236569883): APK не замечала «Zustand: Hervorragend — Refurbished» в собственном описании при шапке «б/у». Теперь состояние проверяется и там. Общие обещания проверки новых товаров не считаются объявлением Refurbished. Два последних случая получены HTML-парсером; браузер перенаправлял их в каталог, поэтому они не приписаны к независимым браузерным вердиктам.

Также явное «только запчасти» не скрывается за соединителем комплекта, а непонятная подпись «chip/title» заменена русским объяснением выбора слова. Обе History-версии повышены до10, чтобы старые неверные агрегаты не подтверждали новую медиану.
