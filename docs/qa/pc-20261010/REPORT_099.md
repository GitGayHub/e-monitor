## Исправления

- В обычном мониторинге один поиск и одно описание получили отдельные кооперативные пределы по 20 секунд с резервом для доставки и сохранения. Сетевые таймауты ограничиваются оставшимся временем. Следующий товар не ждёт неограниченных повторов предыдущего. Это не строгая гарантия 20 секунд: системное разрешение DNS и завершение браузера могут занять дополнительное время.
- Уже полученные при частичном запросе карточки продолжают проверяться. Полностью проверенная находка может отправиться сразу. Неполная популяция не подтверждает медиану; непроверенное описание не даёт права отправки.
- Очередь из-за ограничения числа описаний или времени отделена от настоящих ошибок eBay. APK понимает новый необязательный статус `partial`, показывает число ожидающих этапов и время обновления сервера. Ошибки сети/блокировки остаются ошибками. Старая дата успешного полного прогона сохраняется.
- Страницы CAPTCHA, Access Denied и Pardon Our Interruption не считаются собственным описанием продавца. Обычное описание устройства со словами о безопасности не блокируется. Python и Kotlin проверяют общий набор случаев во всех четырёх форматах.
- Диагностика теста GitHub теперь различает HTTP-ошибку описания, страницу защиты, отсутствие собственного текста, цены и истечение времени. Текст продавца и секреты в диагностический вывод не попадают.
