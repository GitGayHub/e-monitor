## Новая кнопка Telegram

В уведомлениях о лотах добавлена настоящая кнопка **«🔎 Поиск · eBay HTML»** или **«🔎 Поиск · eBay API»**. Для новых HTML-находок сохраняется URL конкретного выполненного запроса: вариант названия, формат продажи, параметры страницы и хост, включая дополнительную страницу, на которой найден лот. Последующее редактирование поиска не меняет эту сохранённую ссылку. Подтверждённая внутренняя лента получает необязательные searchUrl/searchSource/executedQuery в schema1. Старые сообщения массово не пересылались.

Для API кнопка открывает публичную поисковую страницу eBay с фактическим API-запросом и соответствующими поддержанными условиями. Это не адрес API, не токен и **не обещание одинаковой выдачи сайта и API**: эти интерфейсы могут возвращать разный набор лотов. HTML-уточнения, которые API не применял, в такую ссылку не добавляются. Разрешены только публичные HTTPS-страницы поиска eBay; логин/API/чужие домены/параметры доступа исключены. Старые находки без сохранённого URL используют текущие настройки поиска; точный старый алиас для них не восстановлен.

Юридические варианты «обмен исключён» распознаются с артиклями, перечислением и обратным порядком слов.
