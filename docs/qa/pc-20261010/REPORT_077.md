# Проверка 0.077 — сохранение удалённого поиска

Исправлен подтверждённый по коду и воспроизведённый с настоящей базой Android сбой: удаление записи между открытием редактора и сохранением возвращало `null`, а приложение превращало его в пустой сохранённый ID и показывало успех. Теперь оно сообщает, что поиск удалён, не создаёт замену и не отправляет настройки после несостоявшейся записи. Цель редактирования сохраняется и при удалении до завершения загрузки формы.

Проверено:

| Проверка | Результат |
|---|---|
| Удалённый ID при сохранении | Ошибка; создание, отправка и чтение старого успешного статуса не выполняются |
| Редактирование существующей записи | Прежний ID сохранён; отправка только после записи |
| Добавление без связи с GitHub | Локальная запись подтверждена, ошибка отправки показана отдельно |
| Ошибка локальной записи | Отправки нет |
| Настоящая Room-база на эмуляторе | Удалённые варианты не воскресли; создание и отправка не запущены; остальные проверки транзакций успешны |
| Обновление 0.076 → 0.077 | Установка успешна с сохранением всех бизнес-полей исходных 49 поисков |

303 Android-теста и сборка успешны. Четыре новые проверки используют тот же путь сохранения, что редактор. [Доказательство Room](repository077.json), [сборка](build077.json), [экран версии](overview077.png). Удаление одновременно с редактированием проверено на уровне реальной базы и операции сохранения; отдельная визуальная гонка двух экранов ещё не проверена.

Правила бота **1791942417** и версия истории **2** остались прежними: изменение касается сохранения APK. Python-код не менялся, 333 теста подтверждены на этапе 0.076; они не выдаются за новый запуск. Нового Telegram-теста не отправлялось. На физическом телефоне остаётся 0.075; он временно не используется по указанию владельца.

Общая проверка 25 товаров / 100 корзин **PARTIAL**. Дальше — конкретный вариант Nubia Z70, остальные реальные объявления, сетевые ошибки и квота, полный набор настроек и доставки. Подробности предыдущего этапа: [0.076](REPORT_076.md).
