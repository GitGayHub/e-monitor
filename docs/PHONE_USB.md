# Подключение телефона на этом ПК

12 октября 2026 связь восстановлена **без переподключения кабеля**. Windows видел NX741J и исправный интерфейс USB, пока Android Debug Bridge показывал `offline`. SDK adb 37.0.0 и попытка `ADB_LIBUSB=1` не дали рабочей связи. Официальный WinGet adb 37.0.1 с `ADB_USB_LEGACY=1`, без `ADB_LIBUSB`, подключился через NATIVE backend. Старый androidusb.sys версии 1.0.10.1 от 2009 года не заменялся. Эти наблюдения не доказывают причину каждого прошлого обрыва.

Для дальнейшей проверки на Windows использовать один инструмент:

```
python tools/phone_adb.py devices -l
python tools/phone_adb.py -s 324652776507 shell getprop ro.product.model
```

Если телефон уже имеет статус `device`, сервер не перезапускать. Если канал снова `offline`, сначала проверить Windows/ADB и выполнить:

```
python tools/phone_adb.py --recover
```

Восстановление ограничено перезапуском сервера Android Debug Bridge с тем же ключом авторизации. Оно не устанавливает драйверы, не сбрасывает приложение, не перезагружает телефон и не меняет системные переменные Windows. Команды ограничены по времени. Для изменившейся версии инструментов требуется новая проверка; нельзя незаметно подменять её другой adb из PATH.

Не запускать параллельно SDK adb 37.0.0, не включать `ADB_LIBUSB=1` и не оставлять диагностический `ADB_TRACE` в новых запусках. Не называть телефон физически отключённым только из-за `offline` в отладке и не просить пользователя повторно перетыкать кабель без новых доказательств.

Проверять на телефоне только eMonitor. Telegram читать на ПК в фоне; окна ПК не активировать.

Параметр `ADB_USB_LEGACY=1` описан в [официальных release notes Android Platform Tools 37.0.1](https://developer.android.com/tools/releases/platform-tools).
