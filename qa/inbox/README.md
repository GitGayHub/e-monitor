# inbox — вход для stats

1. Скопируй статистический отчёт (или несколько сообщений) из Telegram.
2. Вставь в **`stats_paste.txt`** (создай файл, UTF-8).
3. Запусти из корня репо:

```powershell
python qa/parse_stats_paste.py
```

4. Получишь **`stats_parsed.json`** — каталог позиций для аудита.

Пример формата: `stats_paste.EXAMPLE.txt` (создаётся парсером, если paste отсутствует).

Скрины можно класть сюда же (`*.png`) — агент может прочитать картинку, но paste надёжнее.
